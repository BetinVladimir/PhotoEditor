# Working color profiles

These are real RGB ICC v4.3 profiles generated by LittleCMS2. `profiles.lock.json` records their exact bytes and SHA-256 values. Runtime resolves profiles by ID and verifies the hash; it never substitutes a profile silently.

- `work_rec2020_gamma24_v1`: Rec.2020 primaries, D65, pure gamma 2.4. This is not the BT.2020 video transfer function.
- `linear_srgb_v1`: sRGB primaries, D65, gamma 1, for explicitly linear RAW output.
- `srgb_v1`: LittleCMS sRGB transfer function and primaries, for display/export adapters.

Creation time and platform header are normalized, then LittleCMS recomputes the ICC profile ID. The generated numeric profiles are dedicated under CC0-1.0. The LittleCMS library retains its upstream MIT license; its API definitions are documented in [lcms2.h](https://github.com/mm2/Little-CMS/blob/master/include/lcms2.h).

Regenerate with `scripts/run-platform.sh .venv-platform/bin/python scripts/generate-icc.py`; use `--check` to detect changes. A different LittleCMS build may require an explicit new profile version and regression run. Existing run locks must retain old profile bytes.
