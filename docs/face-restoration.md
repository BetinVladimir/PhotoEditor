# Проверка резкости и восстановление лиц

Версия 0.2.2 измеряет резкость каждого найденного лица на нормализованном crop 512×512. Метрики `face_sharpness` и `min_face_sharpness` записываются в sidecar и `report.json`. Значение ниже `detail.blur_detection.threshold` добавляет `face_blur_detected` и рекомендацию модели; это не останавливает экспорт.

Для локального этапа восстановления выбран CodeFormer. У модели есть управляемый параметр fidelity: высокий уровень сохраняет больше исходной идентичности, низкий сильнее дорисовывает лицо. Начальное безопасное значение — 0.9. Автоматически принимать результат можно только после отдельной проверки сходства личности не ниже 0.75, роста резкости и отсутствия новых клиппингов, ореолов и швов при обратной вклейке.

GFPGAN не выбран по умолчанию: его официальный model zoo прямо указывает небольшое изменение идентичности у естественной версии 1.3. RestoreFormer++ перспективен по качеству и fidelity, но официальный inference использует старый CUDA-ориентированный стек и менее удобен для M2 Max. Ни одна генеративная модель не гарантирует восстановление реальных деталей, которых нет во входном изображении.

Базовый пайплайн обнаруживает необходимость восстановления и сначала применяет детерминированную `detail.face_recovery`. CodeFormer установлен локально отдельным runtime и проверен на `03_family_backlight.jpg`, но не запускается автоматически. Причины: отдельная лицензия NTU S-Lab 1.0, около 376 MB только для основного checkpoint и риск изменения идентичности. Тест использовал fidelity 0.9 и blend 0.65; provenance сохранён рядом с опубликованным JPEG. Автоматический адаптер должен работать только с отмеченными лицами, проверять identity similarity и всегда поддерживать откат.

Официальные источники:

- CodeFormer: https://github.com/sczhou/CodeFormer
- GFPGAN: https://github.com/TencentARC/GFPGAN
- RestoreFormer++: https://github.com/wzhouxiff/RestoreFormerPlusPlus
