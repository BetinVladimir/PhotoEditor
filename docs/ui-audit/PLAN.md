## Порядок и размер

1. UI-01 (1 файл + фикстуры), UI-13 (документ).
2. UI-03 механически, по 10 файлов; затем UI-02.
3. UI-09 (общий набор), затем UI-04…UI-08, UI-10…UI-12 — независимые друг от друга пакеты.
4. UI-14 — приёмка.

«Храповик» UI-01 фиксирует прогресс: потолки цветов и шрифтов сначала равны текущим (75/30), каждый следующий пункт их понижает; финальная цель — 0 вне тем и холстов.

## Что не входит

Изменения API, ролей, CAS-ревизий, журналов попыток и отмены запросов (контракт требует их неизменности); перенос холстов на Paper (остаются специализированными поверхностями); мобильная аппаратная квалификация.
