A nonzero angle, or an angle without a complete crop, remains unsupported. This keeps MappingReport fidelity aligned with the actual crop outcome. The archive-upload route now requires an explicit `format` supplied by the import-format chooser. A missing query parameter no longer silently becomes `photoeditor_bundle`; route-level missing/invalid format cases are authored, NOT RUN.

The bounded XMP parser now requires one actual RDF container with at least one `rdf:Description`, accepting either the XMP wrapper or RDF as root. Unrelated well-formed XML, an empty wrapper and non-description RDF entries are refused instead of being silently mapped to an empty supported sidecar. Hostile-structure unit cases authored, NOT RUN; real Capture One/XMP corpus qualification and full import lifecycle remain open.

Nested `rdf:Description` or `rdf:RDF` is now refused instead of letting a nested description attribute appear as a top-level supported property. Attribute extraction is restricted to a direct RDF description. The nested-property injection case is authored, NOT RUN.

Direct RDF descriptions now accept only the current sidecar subject (`rdf:about=""` or absent) and reject a nonempty `rdf:about` or other RDF subject-identity attribute such as `rdf:nodeID`. Previously a rating attached to a different RDF subject could be mapped to the imported image. Foreign-subject unit cases were authored, NOT RUN; external XMP corpus acceptance remains open.

The XMP parser also rejects `xml:base` at any depth. This prevents an apparently empty local `rdf:about` from being resolved against a foreign base URI. Root- and description-level refusal cases were authored, NOT RUN.
