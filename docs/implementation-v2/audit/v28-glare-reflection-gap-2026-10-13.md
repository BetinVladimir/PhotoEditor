## 2026-10-14 — lease/qualification before full V2 input index

The V28 installation now creates a bounded artifact session with its V2
input-index deferred. It reads only the declared Params, rechecks the current
SQL lease and qualification gates, and then loads the complete V2 input
closure before invoking glare/reflection. The same gates still run after the
handler. Other operations retain eager index loading. An authored ordering
scenario requires index and handler calls only after both live gates; it is
NOT RUN under the code-first plan. This closes a pre-gate closure-download
path, not model qualification, migration or photographic acceptance.

The deferred artifact session now refuses every generic input read and output
stage until `load_v2_index` succeeds; only the exact command Params reader is
available for the SQL gate. A focused unit scenario checks that boundary and
the transition to the verified V2 allowlist. It is authored, NOT RUN.

The V28 handler now repeats both live lease and qualification gates after the
index has loaded and before model execution, closing revocation during that
potentially long closure read. The post-handler gate remains and likewise
checks before and after its index call. Ordering and mid-index revocation
unit scenarios are authored, NOT RUN.
