# Текущий профиль аппаратной проверки

Актуальное решение 2026-10-15: запуск на Apple Silicon / Metal (`mps`) сохраняется. Metal служит средой предварительной проверки и самостоятельным backend для операций, имеющих квалифицированный MPS-путь. У Metal **нет фиксированного потолка 10 ГБ**. Выделенный RTX 3060 12 ГБ / RAM 32 ГБ / Ryzen 5600 является обязательной средой квалификации CUDA для MVP; только на проверках RTX действует лимит 10 000 000 000 байт. Старые результаты Metal не доказывают готовность CUDA.

Профиль `configs/capacity-metal-verification.json` задаёт `gpu_budget_bytes = 2^53−1` как отсутствие дополнительного операторского ограничения по GPU памяти. Это не объявляемый запас: worker сообщает минимум измеренной доступной памяти, доли свободной unified RAM, рекомендованной MPS памяти с учётом driver allocations и оставшегося лимита PyTorch allocator. PyTorch high-watermark guard остаётся включённым; на других Metal устройствах результат пересчитывается по их фактической памяти. CPU/RAM, scratch и конкуренция по-прежнему ограничены профилем. Для worker задать `PHOTO_WORKER_BACKEND=mps` и `PHOTO_CAPACITY_POLICY` с абсолютным путём к профилю.

`PYTHONPATH=workers .venv-platform/bin/python scripts/check-fitting-backends.py` проверяет CPU и MPS на синтетическом fitting fixture. По умолчанию предел MPS равен `torch.mps.recommended_max_memory()`; параметр `--metal-memory-limit-bytes` позволяет оператору явно снизить его. Runner сохраняет PyTorch allocator guard и проверяет `driver_allocated_memory`. Evidence в `work/evidence/fitting-backends.json` содержит запрошенный операторский и фактический предел. Этот benchmark не является квалификацией моделей и качества на фотографиях. Исторический прогон CPU/MPS, выполненный при 10 ГБ, остаётся только историческим evidence; после изменения профиля текущая сборка требует нового запуска.

Серверный `tenant_capabilities()` сообщает `available_backends` только для живого, включённого и квалифицированного worker. UI обновляет capabilities каждые 10 секунд и разрешает AI-операцию только при явном `available=true`; пока capabilities не загружены, отсутствуют, просрочены ошибкой запроса или содержат `unqualified`/`unsupported`, управление отключено. На Mac-only развёртывании CUDA-only операция автоматически недоступна. Если клиент работает на Mac, а удалённый квалифицированный CUDA worker доступен, облачная операция может быть доступна: решает серверная ёмкость, не архитектура клиентского компьютера. Worker дополнительно отвергает неподдерживаемый backend при выполнении. Регистрация CUDA-only операции на MPS запрещена до появления и квалификации реального MPS/CPU пути.
