# Детерминированные алгоритмы и экспериментальные входы

schemas.json задаёт сериализацию. Здесь задана логика. Все вычисления float64 до рендера; запрет NaN/Infinity; порядок reductions по snapshot ordinal. eps=1e-6. Ограничения ресурсов проверяются до allocation.

## Session Brain

Descriptor: proxy longest edge=2048, linear working RGB; luma=0.2126R+0.7152G+0.0722B. Квантили по уровням .1,.25,.5,.75,.9. clipping_fraction — доля пикселей с любым RGB≥1 или <0 до clamp. sharpness — mean squared Laplacian luma после resize shortest edge=512. Embedding L2-normalized, размер 384; несовместимая модель unavailable. neutral_rgb — медианы RGB по pixels, где max-min≤0.05 и luma∈[.1,.9], минимум 1024 samples; иначе null. Лица не используются как нейтральная мишень.

group_scenes: unknown capture time → singleton. Для известных времён добавить camera offset, stable sort(time,ordinal). Соседи — top-k по cosine среди кадров с |time difference|≤time_gap; блоки 128 без NxN matrix. Edge допустим при cosine≥scene_cosine_min и |log2((median_i+eps)/(median_j+eps))|≤scene_log_luma_max. Сортировать edges по убыванию cosine, затем (min ordinal,max ordinal). Union разрешён, если ВСЕ пары объединяемых кластеров имеют cosine distance≤cluster_diameter_max и их временной span≤time_gap. Проверять парами в блоках; худшее O(N²) время, O(Nk) память. Group UUIDv5(snapshot_id, policy_sha+":"+sorted ordinals joined comma). Одиночные группы сохраняются. Confidence=min(pairwise cosine mapped (c+1)/2), singleton=0.

choose_reference: manual exact membership имеет приоритет. Иначе максимизировать sharpness/(sharpness+sharpness_scale) - clipping_penalty*clipping_fraction; tie → smallest ordinal. Не использовать яркость кожи или identity score как критерий красоты.

solve_consistency: reference delta=0. EV_i=clamp(log2((median_ref+eps)/(median_i+eps)),-1,1). Если median_i≤eps или reference≤eps — no_change INVALID_LUMINANCE. При neutral_rgb у обоих: u_c=ln((ref_c+eps)/(i_c+eps)); g_c=clamp(u_c-mean(u),ln(.8),ln(1.25)); иначе g=0 и reason=NO_NEUTRAL_WB. saturation/retouch delta=0. Manual locked → все deltas=0, disposition=manual_locked. Никаких skin correspondences и скрытого optimizer. Применять exposure затем диагональный RGB gain exp(g). Итоговые bounds проверять повторно.

Golden: median_ref=.4, median_i=.2 (без eps-погрешности) → EV≈1; equal RGB → gains0; no neutral → EV допустим, WB0; manual lock → все0. Приёмка отдельно сравнивает clipping и human score с baseline, алгоритм не гарантирует улучшения на каждом сюжете.

## Обучение

RecordCorrection вычисляет changed_paths сервером из двух immutable EditingRecipeV3 одной asset_version: base checkpoint или earlier approved, и обязательный human-approved result. Автор, project, timestamps серверные. base_document предшествует approved_document в одном stream. В учёбу допускаются только параметрические дельты шести координат; crop/selection сохраняются как история, но не дают train example. Generated pixels, неполный approval, отсутствующий consent, недоступный исходник исключаются с кодом причины.

При TrainProfile `RenderCase.base_document` и `approved_document` закрепляют точные SHA исходных EditingRecipeV3, а `base_recipe` и `approved_recipe` указывают на отдельно разрешённые FrozenRecipe. ID последних вычисляются как UUIDv5(run_id, `v23-frozen/{side}/{event_id}`); SHA берётся из canonical bytes результата ResolveRecipe. Admission проверяет все пары до создания draft, публикует их до TrainingManifest и только затем выполняет snapshot freeze. Freeze повторно сверяет исходные документы, consent и готовность FrozenRecipe; отсутствие любой пары блокирует граф.
`BuildTrainingCaseEvidence` выводит шесть координат target как `approved.effective_delta - base.effective_delta` из двух canonical FrozenRecipe после проверки byte SHA, source binding, ICC/model locks и общего base style. Вектор вне bounds исключается, а не обрезается. Features берутся только из проверенного frozen descriptor; клиент не передаёт готовый target. Источник evidence обязан загрузить scoped descriptor, WorkingImage, protected/faces и разрешить оба EditingRecipeV3 до вызова этого компилятора.
`SQLTrainingInventorySource.Load` читает candidate rows под tenant/profile lock в scheduler-транзакции и отпускает locks до object IO; freeze повторно читает эти строки. `SQLTrainingDocumentSource.Load` читает оба EditingRecipeV3 через scoped scheduler-функцию, сверяет stream/version order, approval и consent. `TrainingImageSource.Load` проверяет JCS/SHA WorkingImage, source/canvas/ICC и ready pixel/alpha children через scoped catalog. `SQLTrainingMaskRoots.List` перечисляет JSON refs из immutable closure correction event; `TrainingMaskSelector.SelectProtected` принимает только единственный MaskRef с совпадающим canvas/TransformChain и protected=true, иначе исключает пример без синтетической маски. `TrainingMaskSource.Load` проверяет JCS/SHA root и ready binary child; `SQLTrainingMaskProvenance.Verify` требует canonical child output успешного task того же проекта. EditingRecipeV3 может содержать optional `protected_mask` ArtifactRef на заранее опубликованный MaskRef. BaseCheckpoint сохраняет этот ref, а DiffCorrectionParameters требует его равенства в base/approved. Closure проверяет protected=true, canvas, TransformChain и дочерние MaskPixels; TrainingCaseAssembler выбирает именно закреплённый ref через SelectPinned и SQL event-closure, а provenance требует canonical task output. Для старых документов без поля остаётся выбор единственной маски из closure. `mask.rasterize` публикует standalone `mask_protected_ref` как canonical task output только при ненулевой нарисованной защите; клиентское действие «Pin protection to V2 draft» сверяет current document с историей и закрепляет ArtifactRef через PUT с expected_revision. Первый V2 draft создаётся из серверного VersionBinding и принятой StyleV2 версии того же проекта; если уже получен `mask_protected_ref`, клиент включает его в первый рецепт, и BaseCheckpoint сохраняет тот же ref. Поздняя привязка к существующему draft не меняет base checkpoint и поэтому не делает событие пригодным для обучения с защищённой маской. Если такой ref не закреплён, пример исключается. `TrainingDescriptorSource.Load` использует принятый pre-edit DescriptorShard для того же VersionBinding и сохраняет SHA shard, analysis ID, ordinal, face ref и вычисленные scene12_v1 features. `RenderCase` закрепляет descriptor_shard/descriptor_analysis_id/descriptor_ordinal; fit и evaluate closure объявляют shard входом, а worker пересчитывает все 12 координат по точному кадру и отклоняет несовпадение features/binding/faces.
`TrainingRecipeSource.LoadPair` повторно использует `v2draft.ClosureResolver.ReadResolvedScalars` для точных StyleV2 и CorrectionPlan refs обоих EditingRecipeV3; вложенные pixel-артефакты проверяются при обходе closure. Если LayerStack указан, его JCS/SHA и source binding проверяются отдельно; активный слой исключает параметрический пример. `learning_version_id` разрешается через active eligible model конкретного document и закреплённый pre-edit DescriptorShard; ICC/model locks, source binding, face ref и ordinal проверяются до prediction. `TrainingRecipeSource.loadScalarOverrides` читает каждый ordered Override по scoped ref и принимает только `global` с неизменными curves/LUT и scalar gains/saturation и/или `beauty` с неизменными non-smoothing полями; шаг вычисляется относительно предыдущего session/learning/override вектора и проверяется по bounds. Иные модули, маски и решения кандидатов исключают событие из параметрического обучения. Полный TrainingSource, связывающий inventory, documents, image/masks, descriptor, frozen recipes и recovery, также остаётся обязательным.
`TrainingFacesSource.Load` читает и валидирует exact FaceObservations из descriptor; пустые faces допустимы только в canonical source-bound документе. `TrainingCaseAssembler.Assemble` объединяет проверенные documents/recipes/image/descriptor/faces/protected mask, сверяет master content SHA и original capture lineage с inventory и выводит evidence через `BuildTrainingCaseFromDescriptor`. `TrainingImageSource.DiscoverICC` и `TrainingCaseAssembler.DiscoverICC` получают run-level ICC SHA из scoped WorkingImage и проверенных pixel children до компиляции первого recipe; последующие случаи обязаны совпасть с выбранным ICC. `TrainingModelLockSource.Load` выводит model/dataset lock из активной qualification policy. `TrainingCalibrationSource.Load` получает `dataset_sha` только из DBA-pinned активной qualification policy, читает exact ready artifact и повторно проверяет canonical bytes, SHA, `model_lock_sha`, `dataset_sha` и `qualified=true` валидатором V22. `TrainingContextSource.Load` отвергает расхождение dataset lock между этими двумя источниками, закрепляет policy SHA и выбирает active либо детерминированный zero baseline. `TrainingActiveBaselineSource.LoadActive` читает exact ready artifact текущей eligible active version, сверяет профиль и SHA её training manifest; при отсутствии active version возвращает nil, а disabled/broken active version отклоняет. `BuildTrainingZeroBaseline` создаёт canonical CandidateProfile с нулевыми коэффициентами и run/profile-scoped UUID; `TrainingInputStager.Stage` публикует его после commit recovery и до manifest, а SQL reservation сверяет ref с recovery и отклоняет публикацию после появления active version. Триггер freeze повторно проверяет, что baseline по-прежнему равен ready zero artifact при отсутствии active version либо модели текущей eligible active version. `TrainingSourceResolver.Resolve` собирает inventory и scoped evidence для каждого asset, фиксирует ICC первого подтверждённого случая и явно помечает unsupported случаи; compiler проверяет полное покрытие inventory. `AttachTrainingFrozenRecovery` добавляет точные canonical FrozenRecipe bytes к pending recovery до object IO; SQL сверяет SHA каждой пары с manifest и сохраняет всё в одной транзакции с draft. `Restore` воспроизводит bytes из recovery без выбора нового inventory и допускает повторную публикацию недостающих refs; для старых pending draft без `frozen_jcs` читает только уже готовые FrozenRecipe. После seal recovery заменяется JobTicket. API маршрут TrainProfile теперь подключён к SQLTrainingAdmission при наличии полного набора V23 функций; интеграционные проверки миграций остаются обязательными.

scene12_v1 features: 5 luma quantiles; log(max(neutral RGB,eps)) по трём каналам или три нуля; neutral_present (0/1); clipping_fraction; sharpness/(1+sharpness); person_fraction. Итого 12. Feature extraction использует frozen descriptor до правки. TranslateRecipeV3 сначала разрешает base_style/session_corrections/ordered overrides/layer params в effective parameter vector; дельта отсутствующего параметра0; saturation базового StyleV2=1. Полный порядок и mapping15. Если слой меняет pixels или геометрию, такой event исключается из параметрического обучения. Target — approved minus base vector, с bounds CorrectionVector; превышение bounds исключает пример, а не скрыто обрезается.

freeze_examples: максимум5000, минимум40 пригодных событий из минимум6 сессий. Упорядочить сессии по SHA256(UTF8("2026:"+canonical lowercase UUID)), tie UUID. Holdout первые max(2,ceil(.2*S)); train остальные, минимум4 train sessions и20 train examples, holdout минимум10 examples. Иначе INSUFFICIENT_DATA; не переставлять неудобные сессии для прохождения порога. Дубликаты исходного content SHA и производные одной source lineage считаются одним sample group; оставить самый поздний approved event по (created_at,id) до split, исключить конфликтующую lineage из обеих частей. Snapshot events фиксируется до вычислений.

person mode: person_id один, подтверждённый, same person разрешён в обеих частях, разделение по session. photographer mode: разные люди могут присутствовать в обеих частях, также session split. Обе оценки измеряют новые сессии, не unseen-person generalization. subject_group_id = person_id для person, project_id для photographer; это label, не split key.

fit_delta_model: train means и population std; std<1e-8 →1. X standardized, Y шесть target residuals. Ridge с intercept без penalty: B=(XcᵀXc+λI)^(-1)XcᵀYc, intercept=mean(Y)-mean(X)B; использовать solve, не inverse. λ ∈ [.01,.1,1,10], leave-one-train-session-out CV, все normalization statistics внутри fold. Loss ниже; tie ≤1e-12 → больше λ. Финальный fit на всех train. Holdout не участвует в выборе λ.

L=mean_samples(sum_j(w_j*abs(pred_j-target_j)/scale_j)); weights из Calibration, sum=1±1e-9, scales>0. Baseline — pinned active model predictions, либо zero delta при отсутствии active model (base_profile тогда zero-profile artifact того же формата). Inference clamp по CorrectionVector.

evaluate: один и тот же holdout и renderer для baseline/candidate, outputs не обучаются повторно. candidate eligible только baseline_loss>eps, candidate_loss≤.9*baseline_loss, color_p95_delta≤0, clipping_delta_fraction≤0, safety_regression=false, ≥2 holdout sessions. color_p95_delta — p95 DeltaE2000(candidate render, human-approved render) минус p95 baseline на одинаковых valid pixels. ICC transform pinned в qualification. clipping — изменение доли относительно baseline. Safety regression — новая identity fail либо изменение protected pixels; not_measurable не превращается в pass: version_eligibility=needs_review, immutable human safety review отдельной командой15, Evaluation не переписывается. Нулевой baseline → NO_IMPROVEMENT_POSSIBLE.

## Calibration и модели

Calibration artifact immutable: точные поля schemas.json, model_lock_sha, dataset_sha, qualified. qualified=true принимает только trusted qualification import, не поле от клиента. Корпус должен иметь manifest: sample SHA, лицензия/согласие, split calibration/test, camera/model, scene, expected masks/labels, annotator IDs. Пересечение SHA/source lineage calibration/test запрещено. Пороги выбираются на calibration split; отчёт test immutable. Не подменять test train-выборкой обучения пользователя.

Model family обязан фиксировать реальные bytes SHA, source revision, preprocessing, dimensions, backend/runtime versions, лицензию и reproducible command. До появления этих входов capability unavailable. Это внешние входы, а не разрешение кодогенератору выбрать выдуманные веса. Feature adapters, UI, contracts и negative paths можно генерировать независимо.

## Геометрия, маски и review

MaskExpr: max depth16, max nodes256; union=max(a,b), intersect=min(a,b), subtract=max(a-b,0), invert=1-a. Все leaf masks имеют одинаковый canvas/source; несовпадение 422. Rect x1>x0,y1>y0. Layer IDs уникальны, порядок array — порядок композиции. opacity0 exact bypass; normal=(1-a)S+aP; multiply=(1-a)S+a(S*P); screen=(1-a)S+a(1-(1-S)*(1-P)); linear RGB, alpha хранится straight; premultiply применяется только временно при геометрическом resampling, формулы16.

Semantic homography: fixed RNG seed2026, reprojection threshold calibration.match_error_px_max на proxy coordinates, минимум4 non-collinear matches, inlier fraction≥match_inlier_min; отрицательный Jacobian, horizon crossing, protected overlap>0 → unsupported/review. Confidence=inlier fraction, не вероятность корректности. В v1 без надёжной planar homography результат unsupported; иной segmentation adapter требует новой qualified operation version. local_exposure требует ev!=null, остальные kind ev=null. Human approval никогда не заменяет source/canvas validation.
