# Текущий объём UI-приёмки — 2026-10-20

По последнему решению пользователя пункт 4 текущего плана ограничен размером шрифта и контрастом во всех приложениях с UI. Это уточнение имеет приоритет над прежним требованием немедленной полной WCAG-приёмки.

- Основной текст и поля ввода: продуктовый минимум 16 CSS px; вторичный текст: 14 CSS px. Для native использовать масштабируемые платформенные единицы и проверять фактическое отображение. WCAG не устанавливает такой абсолютный минимум.
- Контраст текста: 4.5:1 для обычного текста, 3:1 для крупного по определению WCAG; применимые исключения документировать. Контраст значимых элементов управления и их состояний: 3:1 в применимых случаях. Проверять реальные фоны, прозрачность, состояния, светлую/тёмную тему.
- Полная клавиатурная приёмка, экранные дикторы, управление фокусом, live regions и остальные критерии прежнего реестра отложены. Уже внесённые исправления сохраняются.
- Полное соответствие WCAG 2.2 AA не заявляется. Существующие 880 NOT_TESTED — исторический полный реестр дальнейшей работы, а не текущий обязательный объём пункта 4.
- Source/unit измерения цветов не заменяют проверку отображения: итоговый отчёт должен указать приложение, экран/состояние, размер текста, пару цветов и измеренный контраст.
