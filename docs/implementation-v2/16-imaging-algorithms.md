# Фотооперации: воспроизводимые алгоритмы v2.2

Нормативная реализация функций; улучшение алгоритма требует новой operation version и повторной qualification. Формулы — выбранный baseline продукта, не утверждение о превосходстве качества. Существующие качественные pipelines и model locks не заменять этими функциями глобально: только новые операции с явным renderer_version=v2.2.

## Общая математика и память

`load_linear(binding)`: WorkingImage/ICC/Canvas/TransformChain из существующих contracts; RGB float32 в рабочем linear пространстве, математика reductions float64, alpha straight сохраняется. Для resampling временно premultiply RGB на alpha, интерполировать, unpremultiply при alpha>1e-6, иначе RGB0; хранить снова straight. При неизменённой геометрии alpha и pixels вне effective mask копируются точно, без convert round-trip. Не clаmp HDR RGB ради отображения; clamp только согласно explicit operation ниже. UI preview transform отдельный. Для optical v2 перенос gamma24↔linear сохраняет исходные primaries/ICC: signed power sign(C)*abs(C)^2.4 и обратный exponent1/2.4, без clamp HDR/negative; nonfinite/float32 overflow→OPTICAL_COLOR_OVERFLOW. Для zero strength transfer round-trip не выполняется. Это не преобразование gamut Rec2020↔sRGB.

Tiles512×512, Gaussian separable kernel exp(−x²/(2σ²)), radius=ceil(3σ), normalize sum1; reflect101 border. Halo — radius каждого последовательного convolution плюс displacement для resampling, проверка scratch до allocation. Для больших halos читать input window из disk-backed array, не весь image. Каждый tile вызывает check_active до чтения и перед stage; result остаётся staged до общей adoption. Интерполяция bilinear, pixel centers=(x+0.5,y+0.5), coordinates normalized x/W,y/H. Маски float32[0,1], NaN/shape/canvas mismatch error.

`compose_safe_delta(S,P,M,Z,strength)`: E=clip(M,0,1)*(1−clip(Z,0,1))*strength; затем для ЛЮБОГО Z>0 установить E=0 (strict protected, soft edge не разрешает изменение protected). Output=(1−E)S+EP. При E=0 exact copy input, strength0 возвращает тот же WorkingImage ref, zero changed mask (можно reused input zero-mask) и pass report. changed_mask=1 если хоть один RGB/alpha bit изменился, иначе0; generated_mask=E>0 для inference-generated pixels, null для deterministic/donor effects. Значения outside effective mask должны совпасть exact. ImageReport.identity либо declared input report, либо null; если операция требует новой identity проверки, compiler добавляет отдельный identity.compare, не недекларированный nested output.

Отчёт содержит finite/clipping checks. При invalid numerical output result failure и нет adopted candidate. Review возвращает корректный кандидат для принятия человеком, не означает автоматический Apply. Геометрические операции меняют координаты protected вместе с изображением; exact outside-mask test применяется ДО warp и не сравнивает разные canvases. У multi-input operations strength отсутствует: правило strength0 к ним не применяется.

## Донор глаз и glare

`validate_donor`: source и donor — разные версии одной session; source/donor_face_id существуют в соответствующих FaceObservations, unique; DonorConfirmation ссылается на подтверждённые person_observations одного active person и granted identity epoch. Server создаёт confirmation, клиент не назначает actor/person сам. Для source и donor min face edge≥calibration.min_face_edge_px; 68 landmarks finite внутри ROI. Недостаток evidence→unavailable, другой person→rejected.

`align_local_patch(src68, donor68)`: индексы landmarks dlib-style0..67; для similarity использовать nose27..35 и eye corners36,39,42,45. Least-squares Umeyama 2D без reflection: center обеих матриц, SVD covariance, исправить знак det(R), s=sum singular values corrected / donor variance, t=srcMean−sR donorMean. Требовать s∈[0.8,1.25], abs(rotation)≤15°, median reprojection≤0.02*source face diagonal, max≤0.05*diagonal. Degenerate variance≤1e-8 reject. Локальный non-rigid warp не используется в v1, чтобы не оставлять скрытого выбора алгоритма. Inverse sample donor с полученным T. Любой запрашиваемый pixel вне donor coverage ⇒ DONOR_COVERAGE, не чёрная подстановка.

`match_patch_color`: кольцо вокруг target mask — Gaussian(M,σ=0.01*face_diagonal)>0.01 && M==0 && protected==0. Минимум64 samples. На каждом RGB канале g=clamp((median(source_ring)+eps)/(median(warped_ring)+eps),0.8,1.25); proposal=warped*g. Нет кольца→review COLOR_MATCH_UNAVAILABLE без изменения цвета (g1), не автоматическое acceptance. Feather = M*Gaussian(M,σ=max(1,0.003*diagonal)), нулевой outside сохраняется. `open_eyes` изменяет только supplied eye mask, не всё лицо, всегда review.

`glare(mode=donor)` — тот же alignment/color/compose на glasses_mask. generative требует donor=null, donor_faces=null; confirmation всё равно подтверждает source person+consent, donor поля в DonorConfirmation должны быть nullable для этого режима (schema). Generated inference заменяет только target mask и маркируется generated; always review. Нельзя автоматически выбирать между режимами или брать внешнего донора.

## Hair, clothing, reflection

`rotate_chroma`: Y=.2126R+.7152G+.0722B, u=R−Y, v=B−Y, θ=hue_delta*pi/180. u'=s*(cosθ*u−sinθ*v), v'=s*(sinθ*u+cosθ*v), R'=Y+u', B'=Y+v', G'=(Y−.2126R'−.0722B')/.7152. Чтобы сохранить Y и избежать новых negative channels, уменьшить обе chroma одной k=min(1,min_{C'<0}(Y/(Y−C'))), затем пересчитать. В HDR верхнюю границу не обрезать. Для source с Y<0→unsupported INVALID_LUMINANCE.

`hair`: chroma выше; detail добавляет d=detail*0.25*(Y−Gaussian(Y,σ=1.2)), proposal RGB +=d; при negative channels ограничить d снизу −min(RGB). Compose через hair mask/protected/strength. Это локальная окраска и detail, не flyaway removal.

`clothing`: L=log(max(Y,eps)); coarse=Gaussian(L,σ=0.01*min(W,H)); fine=L−Gaussian(L,σ=1.2). L'=L + wrinkle_strength*0.5*(coarse+fine−L). L'−L clamp[−ln(1.25),ln(1.25)], luminance gain=exp(delta). Chroma rotation сохраняет Y, после неё умножить RGB на gain. Protected logos required mask; no automatic logo detection guarantee. Review при wrinkle_strength>0, иначе pass при guards.

`reflection`: qualified reflection_rgb family возвращает proposal. Разбить на model input_size patches, overlap64 pixels, reflect pad, weights separable sin²(pi*(i+.5)/tile_size); aggregate weighted sum в scratch. Model input_size должен быть≥128, overlap<input_size/2. sRGB conversion pinned ICC, result вернуть в linear, compose target/protected/strength; always review, generated mask обязателен. Не объявлять скрытые детали восстановленными достоверно.

## Relight

`build_light_field(depth,lights)`: RelativeDepth minmax_valid D[0,1]; invalid samples E=0. Для каждого light normalized(x_l,y_l), radius r, EV e: d0 — bilinear depth в clamped light position; если invalid, ближайший valid по Euclidean distance, tie(row,col); нет valid→DEPTH_UNAVAILABLE. Для pixel(x,y): w=exp(−((x−x_l)^2+(y−y_l)^2)/(2*r²))*exp(−(D−d0)^2/(2*depth_sigma²)). Field F=clamp(sum_l e_l*w,−1,1). Proposal=S*2**F; compose с subject/protected/strength. Depth discontinuities подавляются второй экспонентой; normals не вычисляются, Lambert shading и физический relighting не заявляются. Golden: одна light, pixel в её центре с D=d0, EV1⇒gain2; zeroEV⇒identity.

## Lens

LensProfile относится к exact camera/lens/focal/aperture; допуск metadata focal/aperture≤1e-6, никакой интерполяции профилей в v1. `lens_map` для output center: n=max(W,H), x=(px−cx*W)/n, y=(py−cy*H)/n, r²=x²+y²; f=1+k1*r²+k2*r⁴+k3*r⁶. Distorted input xd=x*f+2*p1*x*y+p2*(r²+2*x²), yd=y*f+p1*(r²+2*y²)+2*p2*x*y. Strength смешивает coordinates distorted с identity. Red/blue дополнительно scale ca_red/blue относительно optical center с тем же strength; green безCA. Vignetting gain=1/max(.25,1+v1*r²+v2*r⁴+v3*r⁶); применить pow(gain,strength). Crop не угадывать: outside coverage alpha0, RGB0; report review если появилась uncovered area. При strength0 exact bypass.

Это нелинейная geometry. Переиспользовать существующий DenseWarpTransform, kind=dense_warp, inverse_field — NPY float32 H×W×2 с координатами input pixel centers в пикселях. Поле вычисляется tiled по формулам выше, роль warp_field; для нового поля lens обязательный marker `pixel_centers=half_pixel`. Потребитель вычитает .5 перед индексированием NPY и обнуляет output вне диапазона source centers. Старые DenseWarpTransform без marker продолжают интерпретироваться как zero-based integer centers; marker отсутствует при их сериализации, поэтому исторические transform_chain hashes сохраняются. Явный null/неизвестный marker запрещён. validity хранится alpha, invertibility=partial, valid_region — canvas bounds. Зелёный канал задаёт geometry map масок; red/blue CA являются photometric correction и отражены в params/report, не тремя несовместимыми Canvas. Все потребители dense_warp обязаны поддерживать resample masks и source correspondence; если существующий consumer не умеет, вернуть UNSUPPORTED_TRANSFORM до записи результата. Не добавлять ложную homography. Forward point для сравнения — Newton inverse map максимум20iterations, central difference h=1e-3px, tolerance1e-4px, singular Jacobian<1e-10→not_measurable. Jacobian positive на сетке33×33 и corners. ResolvedTransform report для lens=null; нелинейное поле находится в WorkingImage.transform_chain.

## Perspective

Manual corners TL,TR,BR,BL normalized, строго convex clockwise в image coordinates. Output W'=round(mean(top,bottom edge lengths)), H'=round(mean(left,right)), минимум1; solve8 equations h33=1 (float64) input quad→rectangle. Determinant abs>1e-10, homogeneous denominator одного знака во всех corners, condition number≤1e8; иначе reject. Crop fraction=1−area(quad)/(W*H), проверять≤max_crop_fraction. Bilinear warp и transformed masks; output canvas сохраняет source lineage.

Auto использует LineSegments c минимум2 nonparallel segments каждой family. Для каждой family найти vanishing point v как right singular vector матрицы normalized homogeneous lines, минимум singular gap s1/s2≥10 (s2=0 допускается как infinity solution); degenerate family reject. Horizon l=cross(v_h,v_v), normalize l_z=1; |l_z|≤1e-8⇒unsupported. Projective rectification H=[[1,0,0],[0,1,0],[l_x,l_y,1]]. После H directions family взять mean unit directions со знаком positive x/y; A — inverse matrix этих двух направлений, rotation/shear. Compose A*H. Выполнить horizon/determinant/bounds checks. Определить output как axis-aligned bbox warped corners, transparent uncovered area; crop_fraction здесь доля uncovered pixels, считать tiled coverage до render. Если cap нарушен, reject; автоматический подбор crop без specification запрещён. Всегда preview+review.

## Panorama и focus stack

`register_pairs`: proxies longest edge2048, linear luma→uint8 round(clamp(luma,0,1)*255). OpenCV ORB nfeatures4000,scaleFactor1.2,nlevels8,edgeThreshold31,firstLevel0,WTA_K2,scoreTypeHARRIS_SCORE,patchSize31,fastThreshold20. cv threads1, RNG seed2026 перед каждой pair. BF Hamming, mutual nearest2 ratio<0.75 в обе стороны; ties по indices. Homography RANSAC maxIters2000, confidence.995, threshold=calibration.registration_error_px, минимум12matches, inlier fraction≥match_inlier_min; singular/horizon checks выше. Порядок pair(i,j) lexicographic, library version locked; byte exact между разными OpenCV builds не обещать. Квалификация привязана к runtime lock.

Panorama planar: все pairs≤190, maximum spanning tree по inlier count, tie(i,j). Graph disconnected⇒UNREGISTERED_FRAME; никаких пропущенных кадров. Root reference_ordinal, compose transforms к root; цикл проверить median reprojection corners≤2*threshold, иначе review REGISTRATION_INCONSISTENT. Глобальный pose optimizer в baseline отсутствует. Cylindrical: сначала inverse cylindrical warp с f=max(W,H) (явно approximate, без обещания восстановленного focal): θ=(u−cx)/f, input x=f*tanθ+cx, input y=(v−cy)/cosθ+cy. Затем тот же registration. Output bounds floor minima/ceil maxima всех transformed corners, caps до allocation. Cylindrical map сохраняется тем же DenseWarpTransform inverse_field; |θ|<pi/2, иначе invalid coverage. Полный chain reference→output включает cylindrical field и registration matrix; fields остальных inputs pinned в lineage и report artifacts, без ложной одной homography для всех кадров.

Blend: each warped frame weight=min(distance_to_valid_border,64)/64; distance Euclidean pixel centers, weight0 outside coverage. Нормировать сумму, fold по input ordinal; zero total⇒alpha0. Exposure compensation намеренно отсутствует; seams/motion всегда review. Motion mask на overlap: max absolute RGB difference>calibration.motion_threshold, dilate disk radius3; сохранить changed_mask для всех geometry-changed pixels, motion fraction в reason/report evidence. Для multi-source lineage сохраняются все исходники, canvas.source_sha256=reference source по existing контракту.

Focus: registration каждого кадра напрямую к reference через ту же homography; reference identity; любой failure⇒reject whole stack. Output reference canvas; bounds≤max_pixels. Для каждого warped Y: F=Gaussian(abs(Laplacian3x3(Y)),σ=1). Weight w=(F+1e-6)^2 * coverage. Gaussian pyramid weights и Laplacian pyramid RGB, L=min(6,floor(log2(min(W,H)))−4), минимум1. Downsample Gaussianσ1 then take even centers, upsample bilinear exact target size. На уровне normalized weighted sum, реконструкция coarse→fine. Reference weight tie не требуется при averaging; все нулевые coverage⇒reference. Motion mask как panorama относительно reference; motion_policy=reject при любом mask>0→MOTION_DETECTED; review→copy reference внутри dilated motion mask и report review. No synthetic content, generated_mask=null.

## Negative

film_base_rgb измеряется пользователем по unexposed film в том же input ICC; все компоненты>0. D_c=−log(max(S_c,eps)/film_base_c). Z=M*D + density_offset. Positive linear P_c=clamp(Z_c/density_range_c,0,1)*2**exposure_ev. Это выбранная linear density inversion; curve/gamma не угадывать. Calibration.input_icc_sha exact; отсутствующий profile unavailable. S=film_base при identityM,offset0⇒black0; S=film_base/e при range1⇒white1. Compose full image strength с сохранением alpha; оригинальный scan неизменен; review всегда.

## Identity и модели

`compare_identity`: при одинаковом Canvas сравнение прямое. При геометрии before resample в after canvas тем же pinned transform/sampler, что операция; сравнение landmarks выполняется в этом canvas. Inverse warp применяется только к координатам, а не как обещание восстановления исходных битов. Unsupported transform/sampler⇒not_measurable. Exact protected/outside-mask guard самой операции проверяется до geometry и хранится в её report; повторная интерполяция не считается доказательством bit-exact сохранения originals. Detector landmarks без сохранения identity может выполняться без matching consent; embeddings только при granted identity consent. Pair faces через minimum-cost bipartite assignment стоимости normalized center distance, candidate edge при IoU≥0.3, ties по face_id; не через автоматическое присвоение person_id. Counts mismatch→review; consent/качество/размер недостаточны→not_measurable. Cosine embedding similarity, drift=median landmark distance/face diagonal. Pass если similarity≥identity_similarity_min, drift≤landmark_drift_max и outside mask error0, protected error0. Numeric guard failure→fail. Пустой successful detector даёт not_measurable наружу IdentityReport; training отдельно фиксирует no_person. Generated mask берётся из declared input lineage; если отсутствует — null, не придумывается.

ModelFamilySpec фиксирует интерфейс адаптера, не название выдуманных весов. Новые модели поставляются как ONNX bundle с точными bytes SHA в существующем ModelLockEntry, runtime_lock_sha, qualification. Adapter допустим лишь после export/reproducibility test; существующий DINOV2/SFD/FAN/segmentation pipeline можно использовать через прежние адаптеры с теми же observable shapes и отдельным lock, не перегоняя все старые модели в ONNX. Для нового ONNX интерфейса input `image` float32 NCHW[1,3,S,S] sRGB[0,1], letterbox bilinear aspect-preserving, padding0; mask при inpaint float32[1,1,S,S], nearest, значения[0,1]. Отсутствующий tensor или неверный shape→MODEL_CONTRACT_ERROR, не reshape по догадке.

### Композиция adjustment-слоя

`compose_layer_tile` принимает совпадающие float32 straight RGB тайлы source и proposal в одной ColorSpace/ICC, float32 маску и optional float32 alpha/protected. E=clip(mask,0,1)*opacity; protected>0 строго устанавливает E=0. Blend вычисляется в том же working linear RGB: normal=P, multiply=S*P, screen=1-(1-S)*(1-P). Результат RGB=S+E*(Blend-S), затем обратная transfer function в исходную encoding без gamut conversion/clamp HDR. Alpha adjustment-слоя интерполируется source_alpha+E*(proposal_alpha-source_alpha); absent alpha означает1. Это не повторное source-over накопление opacity на каждом этапе. Opacity применяется один раз.

E=0 сохраняет source RGB/alpha exact, normal E=1 сохраняет proposal exact, неизменённые значения сохраняют исходные bits без transfer round-trip. changed_mask сравнивает итоговые RGB/alpha bits. Legacy uint16 alpha не квантовать скрыто: adapter обязан явно выбрать сохранение исходного alpha ref либо объявленную конверсию в float32; kernel не принимает uint16. Тайлы≤1024×1024; workspace admission≥256bytes/pixel; float32 overflow/nonfinite запрещены. Материализация, provenance, совместимость canvas/transform chain и публикация остаются обязанностью operation adapter.


### Frozen входы внутренней композиции слоя

`LayerComposeParams` (`operations/layers/contracts.py`): schema_version=1, base:VersionBinding, source_result:ArtifactRef|null, proposal_result:ArtifactRef, mask:MaskExpr, protected_mask:ArtifactRef|null, opacity:[0,1], blend:normal|multiply|screen. Nullable refs обязательны в JSON, null явно означает отсутствие. Proposal указывает на родительский ImageResult; adapter извлекает WorkingImage/report/generated_mask из проверенного declared closure. source_result=null разрешается только для original snapshot WorkingImage, что обязан доказать relational graph guard; иначе source_result.working_image обязан совпадать с base.source. Маска требует exact base.canvas_hash и depth/node limits.

Registry/activation `layer.compose` не включать до завершения compiler/worker/adoption и проверки inherited generated-mask lineage. При наличии generated masks родительских ImageResults нельзя молча публиковать output.generated_mask=null; вычисление/проверка наследуемого покрытия — обязательный шаг adapter/adopter. Runtime helpers уже вычисляют и публикуют наследуемое покрытие с проверкой canvas/chain и бинарных значений. До production registration остаются relational admission, frozen task scope, adopter и проверка полного контура. Машинная JSON Schema `LayerComposeParams` генерируется из `build-spec.py`; границы depth/node и совпадение canvas дополнительно проверяются runtime-компилятором маски.


### Наследуемое generated dependency coverage

`generated_coverage` принимает binary float32 маски source/proposal в совпадающей геометрии. E вычисляется как в композиции, включая strict protected. Для normal source coverage сохраняется при E<1; при E=1 source заменён proposal. Для multiply/screen source coverage сохраняется консервативно независимо от E, потому что blend зависит от source. Proposal coverage наследуется при E>0. Итог — binary union этих зависимостей; отсутствие обеих масок даёт null. Bit-identical proposal всё равно может иметь generated dependency. Это покрытие потенциальных зависимостей, а не утверждение об аутентичности фотографии. Исходные маски должны быть извлечены из проверенных parent ImageResults и уже приведены к target canvas/chain; утраченные upstream claims должен предотвращать graph/adoption guard. Kernel не восстанавливает отсутствующую историю по пикселям.
