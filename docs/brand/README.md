# Framevela — логотип и иконки

Контур стилизован под фотоаппарат: выступ сверху и круглый объектив обозначают фотографию. Золотистая кнопка воспроизведения внутри объектива обозначает видео. Искра в верхнем правом углу сохраняет связь с AI и творческими инструментами. Знак объединяет фото, видео и AI без дополнительных букв и мелких деталей. Предыдущие версии сохранены в `archive/v1` и `archive/v2`.

## Оригиналы

- `framevela-logo.svg` — вектор для светлого фона, масштабируется без потери качества.
- `framevela-logo-dark.svg` — вектор для тёмного фона.
- `framevela-logo-4096.png`, `framevela-logo-dark-4096.png` — PNG 4096 × 4096 с прозрачным фоном.
- `framevela-app-icon.svg`, `framevela-app-icon-1024.png` — квадратная непрозрачная иконка приложения.

Цвета: тёмный `#292C29`, светлый `#F2EDE3`, охра `#A66B32` на светлом и `#E0AD70` на тёмном фоне. Минимальный размер отдельного знака — 24 px; защитное поле — четверть ширины знака. На маленькой вкладке браузера используется специальный favicon.

## Подключение

Portal: `apps/portal/src/app/icon.svg`, `favicon.ico`, `apple-icon.png` подключаются через соглашения Next.js. В `apps/portal/public` находятся дополнительные растровые размеры, SVG, ICO и `site.webmanifest` для последующей PWA-интеграции. Сам файл webmanifest ещё не делает портал PWA.

Photographer: `apps/photographer/app.config.js` расширяет существующий `app.json`, сохраняя slug, схему ссылок, плагины и остальные параметры. Он задаёт имя Framevela, иконки iOS, Android и web. Исходники находятся в `assets/brand` внутри приложения.

iOS: непрозрачная квадратная PNG 1024 × 1024, без заранее скруглённых углов. Android: обычная иконка 1024 × 1024, прозрачный адаптивный передний слой и одноцветный слой для тематических иконок. Содержимое адаптивных слоёв укладывается в центральную безопасную область. Фон задаётся отдельно; маску выбирает система.

Чтобы новые иконки появились в установленном приложении, необходима новая нативная сборка. Изменение файлов не обновляет уже установленное приложение. Публикация в магазинах не выполняется этим изменением.

Рядом с текстом Framevela знак декоративный (`alt=""`); у отдельного изображения `alt="Framevela"`. Ссылка со знаком должна иметь локализованное доступное имя.
