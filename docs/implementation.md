# Реализация 0.3.3 и запуск

Дата: 19 сентября 2026.

**Тип реализации:** текущий пайплайн улучшения качества фотографий.

Рабочий CLI и скрипты реализованы. Версия 0.3.3 добавляет финальный баланс белого по нейтральным средним тонам, плавную защиту светов и немного более активное подавление локальных красных дефектов кожи. После этого адаптивная цветокоррекция восстанавливает естественный тон лица.

## Запуск

```bash
cd /Users/freelancer/Documents/PhotoEditor
./run-e2e.sh
./run.sh render --resume
```

`run-e2e.sh` устанавливает фиксированные пути input/output/config теста. `run.sh` принимает `PHOTO_INPUT_DIR`, `PHOTO_OUTPUT_DIR`, `PHOTO_CONFIG_FILE`; без ENV использует e2e-пути. Первый запуск вызывает `scripts/setup.sh`. Зависимости из `apps/local-editor/requirements.lock`, пакет устанавливается editable. Setup скачивает веса с официальных versioned URLs и проверяет SHA-256. Веса не скачиваются во время render; фотографии не передаются в сеть.

Настройки e2e: `e2e/config/studio_soft.yaml`. Для произвольной серии: `configs/natural.yaml`. Схема: `schemas/config.schema.json`.

Коды: 0 — успешная команда / рендер без технических флагов; 2 — ошибка конфигурации/окружения; 3 — хотя бы один failed/needs_review; 4 — отмена; 5 — необработанная ошибка выполнения. Даже код 0 рендера не является визуальным PASS: отдельный `acceptance.json` явно указывает отсутствие утверждённых golden references.

## Реализованный тракт

1. Сканирование JPEG/PNG/TIFF, SHA-256, запрет совпадения/вложенности input/output, игнорирование symlinks, проверка размеров и профиля.
2. Применение EXIF orientation один раз. ICC-конвертация 8-bit источников в sRGB; 16-bit RGB TIFF поддерживается только в sRGB, без промежуточного 8-bit преобразования. RAW/HDR/alpha/multipage требуют будущих адаптеров и явно отклоняются при чтении неподдержанного содержимого; RAW-расширения не входят в whitelist.
3. MediaPipe Face Landmarker 0.10.21: полный кадр и перекрывающиеся crop нескольких масштабов. SelfieMulticlass: маски face/body skin, confidence; отдельная защита глаз/бровей/губ. Семантика на малом разрешении остаётся приближённой.
4. Двухпроходный план: анализ всех кадров → target/median exposure → frozen per-file EV. Изменение конфига/входов/моделей меняет план. Cache key анализа не зависит от ползунков эффектов, но включает источник, модели, analysis revision и decoder policy; frozen plan дополнительно включает engine version.
5. Full-resolution float32 tiles: linear-sRGB exposure и WB; low-frequency light field, shoulder светов; sRGB texture-aware skin smoothing, уменьшение красноты/блеска, контурный свет; кривая/насыщенность; thresholded sharpening с защитой кожи.
6. Healing явных маленьких circles выполняется локальным inpaint. Дополнительно реализовано консервативное автоматическое подавление локальных красных дефектов кожи с защитой нейтральной кожи; сила задаётся через `beauty.blemishes.auto_strength`.
7. Необязательная геометрия: единое горизонтальное inverse displacement field для боковых контуров лица и явно размеченных body_regions, один resample, проверка Jacobian. Лицевые центральные зоны защищены; фон и индивидуальность всё равно требуют визуальной проверки. Поза/талия автоматически не восстанавливаются.
8. 16-bit sRGB TIFF с ZIP, JPEG sRGB 4:4:4, preview, контактный лист, before/after crops лиц, sidecars, report и acceptance. EXIF намеренно пока не переносится; ICC записывается.
9. После основного JPEG blur-gate выбирает только проблемные кадры. RetinaFace выравнивает каждое лицо из полноразмерного изображения в crop 512×512. CodeFormer строит кандидаты fidelity 0.85/0.92/0.97; ArcFace IR-SE50 проверяет сходство, а QA — прирост резкости и клиппинг. Принятый crop смешивается с исходным и вклеивается через face-parsing mask. 16-bit master остаётся детерминированным.
10. Финальная `highlight_cleanup` выполняется после восстановления лиц. `post_white_balance` корректирует каналы в linear light и добавляет highlight shoulder. Затем `face_color_finish` возвращает серым участкам насыщенность и теплоту по эталону средних тонов того же лица. Оба этапа работают внутри skin-mask, защищают глаза/брови/губы и публикуют `finished/*.jpg`.

Каждый кадр обрабатывается последовательно, тайлы 768 px по умолчанию. Halo вычисляется из радиуса операций. Финальные пиксели берутся из оригинала, proxy переносит только маски и световое поле. Полные вход/выход и опциональный буфер warp удерживаются в памяти: это не полностью out-of-core реализация, но не создаётся float32 копия всей коллекции.

## Повторяемость и ошибки

OS file lock запрещает два concurrent writer в одном output. JSON/изображения записываются через временный файл и replace. При KeyboardInterrupt run помечается cancelled; незавершённый TIFF/JPEG не получает complete-sidecar. Resume проверяет plan hash и SHA-256 готовых выходов. Ошибка одного изображения записывается отдельно, оставшиеся обрабатываются. Повреждённый analysis cache проверяется по checksum и пересоздаётся.

Model manifest с URL и hashes: `apps/local-editor/src/photoeditor/models.py`. Зафиксированы официальные MediaPipe веса; проверки лицензии весов для распространения отдельного продукта и модельные cards остаются задачей перед дистрибуцией.

## Редактор

`./scripts/setup.sh --studio`, затем `./run.sh studio`. Реализованы список входов, YAML-редактор всей схемы, validate/save, отдельный worker через QProcess, before/after proxy, batch и cancel. Устаревший preview после изменения конфигурации не отображается. Ползунки, кисти, точный интерактивный ROI, полноценная цветопроба экрана и менеджер групп остаются будущей работой. Для 100% проверки использовать экспортированные crops.

## Проверки

Автоматические tests покрывают строгую схему и aliases/duplicate keys, конфликт geometry, image overrides, realpath input/output, цветовой roundtrip, no-op 16-bit, TIFF/ICC, ориентацию, tiled/full agreement, границы geometry, source IDs, lock, частичную ошибку партии, resume и восстановление повреждённого анализа.

`./.venv/bin/python scripts/verify-e2e.py` проверяет полный результат: 6 master TIFF, 6 delivery JPEG по 6000×4000, ICC, 16-bit masters, 10 найденных лиц, 20 face crops, неизменность SHA-256 всех входов и соответствие hashes артефактов. Он не утверждает студийное визуальное качество.

PySide6 прошёл smoke-проверку создания окна, загрузки шести входов и валидации конфига в offscreen-режиме. Полная проверка всех GUI-жестов не выполнялась.

## Известный разрыв с целевым e2e

Классическая коррекция улучшает читаемость тёмных лиц, тон и общий свет, но не гарантирует превращение жёсткого солнца/клиппинга в ровный студийный свет. Нельзя достоверно восстановить отсутствующую фактуру или вывести нативные 24-Мп детали из увеличенных 1536×1024 fixtures. `NEEDS_REVIEW` для этого набора ожидаем: геометрия и невосстановимые пересветы требуют оценки, golden references пока не утверждены.

Отсутствуют: linear Rec.2020/ProPhoto, RAW, автоматический WB/группировка освещения, полноценное моделирование источников света, автоматическое удаление всех дефектов, teeth/sclera и вся расширенная UI-часть. ArcFace gate снижает риск изменения личности, но не является доказательством пиксельной достоверности синтезированной фактуры.
