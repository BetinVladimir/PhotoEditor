## Spec
In `_run_built_worker`, immediately after `database.ping()` insert:
```python
from .clock_guard import check_clock_skew, max_skew_seconds
if hasattr(database, 'server_now'):
    check_clock_skew(database, max_skew=max_skew_seconds())
```
(import inside the function: the module `test_service_lazy_imports.py` forbids heavy top-level imports; this one is light but keep it local anyway.) The `hasattr` keeps fake databases in existing tests working. No other change.
