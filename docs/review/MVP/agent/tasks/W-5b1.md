## Goal
Building block for resumable downloads. The server accepts `Range: bytes=<start>-<end>` with `end-start < 16 MiB` and answers `206` with `Content-Range: bytes start-end/total`, plus the same `X-Photo-SHA256` / `X-Photo-Artifact-ID` headers.

## Spec
Add `Gateway.open_range(self, ref, start: int, length: int)` returning `(response, connection)`:
- validate `0 <= start`, `1 <= length <= 16*1024*1024` (else `ValueError`);
- same connection/headers/exception translation as `open_stream` (`SSLError` -> `GatewayError('CONFIG_INVALID')`, `OSError/HTTPException` -> `GatewayError('DEPENDENCY_UNAVAILABLE', True)`, close the connection on any error);
- request header `Range: bytes={start}-{start+length-1}`;
- require status 206, `Content-Range` exactly `bytes {start}-{start+length-1}/{total}` where `total` is a positive int (the last block may be shorter: then the end in the header is `total-1` and `Content-Length` is smaller — accept `end = min(start+length-1, total-1)`); `Content-Length` must be a single decimal equal to `end-start+1`; SHA and artifact-id headers must match `ref` (else `GatewayError('ARTIFACT_HASH_MISMATCH')`); `start >= total` -> `GatewayError('GATEWAY_RESPONSE_INVALID')`;
- call `self._status(response)` first, `self._check()` at the end.
Return the parsed `total` as a third tuple element: `(response, connection, total)`.

## Test
Subclass or monkeypatch `Gateway` pieces: build a `Gateway` instance via `object.__new__(Gateway)` and set the private attributes used by the method (`_check`, `_headers`, `_connection`, `_lease` as SimpleNamespace). Fake connection/response objects return scripted headers. Cases: ok middle block; ok short last block; wrong Content-Range; status 200 instead of 206; sha mismatch; `length` too large -> ValueError.
