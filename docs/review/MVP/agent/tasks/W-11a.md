## Goal
Building blocks for the network-fault tests (plan W-11) that need NO real stand to be unit-tested.

## Spec
- `toxiproxy.py` (stdlib `urllib` only): class `Toxiproxy(base_url)` with `create_proxy(name, listen, upstream)`, `delete_proxy(name)`, `add_toxic(proxy, type, stream, attributes, name=None, toxicity=1.0)`, `remove_toxic(proxy, name)`, `reset()`; they call the documented toxiproxy HTTP API (`POST /proxies`, `POST /proxies/{p}/toxics`, `DELETE ...`, `POST /reset`). Helpers `cut(proxy, seconds, sleep=time.sleep)` (adds a `timeout` toxic with `timeout=0`, waits, removes it - guaranteed removal in `finally`) and `degrade(proxy, latency_ms, loss_percent)` (`latency` toxic + `slicer`/`limit_data` is NOT needed; use `latency` and `bandwidth` only).
- `conftest.py`: register marker `fault`; fixture `stand` that `pytest.skip`s unless env `PHOTO_FAULT_STAND=1` and `TOXIPROXY_URL` are set, else yields `Toxiproxy($TOXIPROXY_URL)`.
- `test_toxiproxy_client.py`: start `http.server.ThreadingHTTPServer` on 127.0.0.1:0 in a thread that records method/path/body and returns 200 `{}`; assert the exact request sequence for `create_proxy`, `cut` (create toxic -> sleep -> delete toxic, with a fake `sleep` that also checks the toxic exists) and that `cut` removes the toxic when `sleep` raises.

## Do not
- No third-party packages. Do not import anything from `workers/` here.
