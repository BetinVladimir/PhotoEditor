## Goal
Lease deadlines come from the database clock but are converted with the worker's wall clock (`ExecutionContext.__init__`). A GPU host with a wrong clock silently gets a wrong write window. Refuse to start when the skew is too large.

## Spec
1. `database.py`: add a method right after `ping`: `def server_now(self): row = self._query('SELECT now()', ()); return row[0]`. Do not modify any other function (pinned by a source-pin test).
2. `clock_guard.py`:
```python
class ClockSkewError(RuntimeError): pass
def max_skew_seconds(env=None) -> float:   # WORKER_MAX_CLOCK_SKEW_SECONDS, default 2.0, 0 disables, clamp [0, 60]
def check_clock_skew(database, *, max_skew: float, local_now=None) -> float:
    """Return skew in seconds (local - server). Raise ClockSkewError('CLOCK_SKEW') when abs(skew) > max_skew (and max_skew > 0)."""
```
`local_now` is a callable returning an aware UTC datetime (default `lambda: datetime.now(timezone.utc)`). Measure round trip: `t0=local_now(); s=database.server_now(); t1=local_now()`; use the midpoint `t0 + (t1-t0)/2` as local time.
## Test
Fake database with `server_now()` returning a fixed aware datetime; inject `local_now`. Cases: skew 0.5 s ok; skew 5 s raises; `max_skew=0` never raises; env parsing and clamping.
