## Goal
One scenario of the W-11 network-fault suite, written so that it is collected and SKIPPED when no stand is available (`stand` fixture), and runs for real on the stand prepared by a human (see NOT-CODEGEN.md, checklist H-W11).

## Scenario
Worker death after a completed stage.
Detail: SIGKILL the worker after stage 1 of a two-stage task; another worker resumes without re-running stage 1 results being duplicated.

## Spec
- File `test_node_death.py`, marker `@pytest.mark.fault`, uses the `stand` fixture, the helpers `cut`/`degrade` and the assertions of `invariants.py`.
- Stand access (submit a task, read results) goes through small local helper functions at the top of the file that read connection settings from environment variables (`PHOTO_FAULT_DATABASE_URL`, `PHOTO_FAULT_API`, ...) and raise `pytest.skip` when absent. Do not guess endpoints: keep them as TODO-free thin wrappers around variables.
- Verification of this card is "collects and skips cleanly" (the stand run is a human step).
